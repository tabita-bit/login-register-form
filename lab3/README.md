Login & Register Form

A React application featuring login and register forms built with custom, reusable input components.

Features
Login form with email/password fields
Register form with custom input validation
Reusable custom input component
Built with modern React (v19) and fast Vite tooling
Tech Stack
React 19
Vite
ESLint
Run Locally
bash
npm install
npm run dev

Then open the local URL shown in the terminal (usually http://localhost:5173).

Build for Production
bash
npm run build
